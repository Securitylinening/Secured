# CyberNox GreyHat

A responsive cybersecurity landing page built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in any modern browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html` and `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

## Notes

The contact form is currently front-end only and displays a confirmation message. Connect it to a backend or form provider before using it for production email collection.
